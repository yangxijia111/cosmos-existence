## 1. 用户故事

| # | 用户故事 | 验收 |
|---|---|---|
| U1 | 作为首次访问者，我看到一片纯粹的黑暗与微弱呼吸的星光，点击"开始"后被带入宇宙的诞生 | 首页 void 状态无任何 UI 噪音；点击后有过渡动画 |
| U2 | 作为体验者，我从奇点开始连续观看宇宙 138 亿年的演化，画面是实时生成的而非视频 | 6 纪元程序化动画连贯播放；无预渲染视频文件 |
| U3 | 作为探索者，我可以拖动时间轴跳转到任意宇宙纪元 | 拖动时间轴实时切换纪元与尺度因子 |
| U4 | 作为思考者，演化结束后第一个哲学问题自然浮现，引导我进入哲学图谱 | earth 纪元结束 → 问题淡入 → CTA 可点击 |
| U5 | 作为浏览者，我在图谱中看到 10 个哲学问题及其关联，点击进入任一问题深入了解立场与论证 | 图谱可拖拽缩放；详情页 SSG 可直达 |
| U6 | 作为移动端用户，我在手机上也能完整体验全部流程 | 触控拖动时间轴；图谱退化为列表+迷你图 |

## 2. 体验流分镜

```
[黑屏 · 呼吸微光]        — void        0s
   ↓ 点击"开始"
[光晕涌现 · 过渡]        — awakening   ~2s
   ↓
[宇宙演化 6 纪元]        — cosmos      ~90s（可拖动控制）
  奇点 → 暴胀 → 粒子 → 恒星 → 星系 → 地球
   ↓ 自动进入
[第一个哲学问题淡入]     — question    停留
   ↓ 点击"进入探索"
[/explore 哲学图谱]
```

## 3. 文案基调

- 旁白：短句、克制、诗性但不矫情；每句不超过 20 字
- 科学标签：精确术语 + 通俗注解（如"普朗克时期 · 10⁻⁴⁴ 秒"）
- 哲学内容：呈现立场光谱，不做评判性结论

## 4. 功能规格（P0/P1/P2 与主纲领第 2.1 节一致）

P0 全部功能按主纲领验收；P1 为视觉基调与质量门禁；P2 为 LLM/RAG、思想实验、Journey 的类型与接口预留，第一版不实现 UI。

## 5. 非目标（Non-goals）

- 不做用户账号系统
- 不做哲学百科式的长文罗列
- 不做社交分享裂变功能
